# EchoScript: Professional Audio Intelligence

EchoScript is a high-performance recording and transcription platform designed for professional environments. It provides reliable 24/7 audio capture and human-level AI transcription powered by Google Gemini 1.5.

## Key Features
- **Reliable Capture:** Automated 30-minute background recording cycles.
- **AI Intelligence:** Advanced transcription using Gemini 1.5 (Pro and Flash).
- **Secure Archive:** Efficient local storage with automated audio cleanup.
- **Clean Interface:** Minimalist design focused on utility and clarity.

## Getting Started
1. **Clone & Install:**
   ```bash
   git clone https://github.com/zihaaaad/EchoScript.git
   flutter pub get
   ```
2. **Setup AI:**
   - Obtain a Gemini API Key from [Google AI Studio](https://aistudio.google.com/).
   - Enter the key in the app's **Settings**.
3. **Run:**
   ```bash
   flutter run --release
   ```

## Architecture
Built with **Clean Architecture** and **Riverpod** for robust state management and scalability.
